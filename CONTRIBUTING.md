# Contributing

Keep the community app independently buildable with the included wrapper and public dependencies. Preserve local profiles, favorites, accessibility, and the unofficial-fan-app disclaimer.

Run debug assembly, Android lint, and JVM tests before proposing a change. Add focused tests for parsing or state-handling changes. Device tests are available separately; describe which checks you actually ran.

Do not commit credentials, signing keys, account databases, personal machine paths, provider access tokens, private service URLs, build caches, or generated APKs. Use synthetic fixtures where possible. Retain upstream license notices and attribution when introducing third-party material.

This edition intentionally has no production account, notification enrollment, administrative, or watcher integration. Any proposed new service must use contributor-owned infrastructure and undergo an explicit privacy/security review. A source-code contribution does not grant access to another deployment.
